Loose Balloons

Every balloon is an object in a running .NET app, and every rope is a reference. Lights run along a rope from the balloon that holds to the balloon that is held.

The tower is the root. If ropes lead from the tower to a balloon, however long the way, the app can still reach it: it is alive. Anything else is garbage, even if it is tied to other garbage, and even if it holds something alive. Shoot what is loose. The memory is really freed.
